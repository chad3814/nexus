# nexus

The site for [casefiles](https://github.com/chad3814/casefiles): spoiler-gated character and
world compendiums for book series, generated by [dossier](https://github.com/chad3814/dossier).
Live at [casefiles.nexus](https://casefiles.nexus/).

Pick a series and your reading position, and every entity's description, significance and
aliases are shown as of that point, never with later knowledge. The position is remembered per
series in the browser.

## Series

| Id | Series | Books |
|---|---|---|
| `dcc` | Dungeon Crawler Carl | 1–8 |
| `hierarchy` | The Hierarchy | 1–2 |
| `hwfwm` | He Who Fights with Monsters | 1–13 |

Published series are listed in `SERIES_IDS` in `scripts/sync-data.mjs`. Titles and authors come
from each series' `casefiles/<id>/series.json`.

## Data

`npm run sync-data` copies each series' `output/registry.json`, `log/descriptions.json` and
`log/aliases.json` from casefiles into `public/data/<id>/`, and writes a series manifest to
`public/data/series.json`. It reads `../casefiles` by default; set `CASEFILES_DIR` to point
elsewhere.

## Develop

```bash
npm install
npm run sync-data   # needs a casefiles checkout
npm run dev         # http://localhost:3000
npm test            # vitest
npm run e2e         # playwright
npm run lint
```

## Deploy

`.github/workflows/deploy.yml` builds a static export and publishes it to GitHub Pages on every
push to `main`, or on demand (`gh workflow run deploy.yml`). It shallow-clones casefiles with a
read-only deploy key, so **push casefiles first**; a data-only change needs a manual run.
